## Instalación local

Para poner en marcha el panel de control táctico localmente, sigue estos comandos en tu terminal:

**En Windows:**
```bash
python -m venv venv
cd venv
Scripts\activate
```

**En Linux/Mac:**
```bash
python -m venv venv
cd venv
source bin/activate
```

1. Instalar dependencias: Este proyecto utiliza Flask como motor de backend.
pip install flask

2.- Clonar el repositorio:
git clone [https://github.com/Agent3835/turbo-chill-road.git](https://github.com/Agent3835/turbo-chill-road.git)
cd turbo-chill-road

3. python main.py
